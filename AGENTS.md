## Local commands and constraints

- The application runs from the repository root with `make run`.
- Database operations use PostgreSQL through Streamlit's `neon` SQL connection.
- Keep `.streamlit/secrets.toml`, credentials, generated bytecode and virtual
  environments out of Git. Tests must use fakes or a disposable test database.
- Do not run tests against the production database or paid APIs by default.
- This initial onboarding, product review and ORM draft belong on the feature
  branch requested by the owner. Keep the default branch unchanged. The ORM
  draft has not been accepted for implementation.
